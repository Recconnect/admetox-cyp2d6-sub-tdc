# TDC Submission Metadata

## Benchmark

- Benchmark group: ADMET Group
- Endpoint: `CYP2D6_Substrate_CarbonMangels`
- Task: binary classification
- Metric: AUPRC
- Split: official TDC scaffold split (532 train_val / 135 test)

## Model

- Name: ADMETox GIN-ContextPred fine-tune
- Backbone: `gin_supervised_contextpred` (Hu et al. 2020, ContextPred self-supervision on ZINC15; official dgllife checkpoint)
- Forward: pure-PyTorch reimplementation (`gin_pure.py`), numerically verified against dgllife
- Head: mean-pooled node embeddings -> Linear(300 -> 1), dropout 0.1
- Loss: BCEWithLogitsLoss, pos_weight = neg/pos ~ 3.6
- Optimizer: AdamW, lr 1e-3, wd 0, 5% warmup
- Protocol: train on all train_val (532); per-seed stratified 15% inner-val early stopping on AUPRC (60-epoch cap); best-epoch model predicts test
- Independent runs: 30 (TDC requires >= 5)
- Source: https://github.com/Recconnect/admetox-cyp2d6-sub-tdc

## Reproduction

```bash
pip install -r requirements.txt
pip install PyTDC --no-deps
python run_cyp2d6_sub.py
```

The default command retrains all 30 seeds end-to-end (downloads the ~8 MB pretrained checkpoint on first run). Re-running on identical software reproduces the per-seed AUPRCs; cross-machine runs reproduce the score distribution (mean ~0.742, vector ~0.768).
